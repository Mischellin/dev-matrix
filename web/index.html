🔬 Evaluation Methodology & Principles

Built to prevent benchmark gaming and evaluate true autonomous software engineering.

1. Zero-Leakage Verifier

Models never receive the acceptance tests in their context. Acceptance tests are mounted into an isolated git worktree only during evaluation phase. A score of 100% test pass is mandatory.

2. Cross-Family Review

Solutions written by Claude are reviewed by Codex or GPT; solutions by Codex are reviewed by Sonnet. Reviewers are calibrated for strictness bias and accuracy against human verification.

3. True Cost-per-Pass

Measuring total expenditure across both successful and failed attempts: Cost/Pass = Total API USD / Successful Runs
