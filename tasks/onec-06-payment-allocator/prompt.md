# 1С: Автоматическое разнесение входящей банковской оплаты по заказам клиентов (FIFO)

## Задача
В модуле `src/onec/РазнесениеПлатежей.bsl` реализовать экспортную функцию 1С:Предприятие 8:
```bsl
Функция РазнестиОплатуПоЗаказам(ПараметрыПлатежа, ТаблицаЗаказов) Экспорт
```

Модуль должен быть написан на чистом языке 1С:Предприятие (BSL) с использованием стандартных русскоязычных конструкций и типов платформы: `Структура`, `ТаблицаЗначений`, `Массив`.

## Входные параметры

1. `ПараметрыПлатежа` — `Структура`:
   - `СуммаПлатежа` (Число) — сумма входящего платежа из выписки.
   - `Контрагент` (Строка) — наименование или ИНН клиента.
   - `Договор` (Строка) — договор расчетов.
   - `ДатаПлатежа` (Строка) — дата выписки.

2. `ТаблицаЗаказов` — `ТаблицаЗначений` со следующими колонками:
   - `НомерЗаказа` (Строка) — уникальный номер заказа.
   - `ДатаЗаказа` (Строка вида `"ГГГГ-ММ-ДД"`) — дата оформления.
   - `СуммаЗаказа` (Число) — полная сумма заказа.
   - `ОплаченоРанее` (Число) — сумма, оплаченная по заказу ранее.
   - `СтавкаНДС` (Строка) — `"20%"`, `"10%"` или `"Без НДС"`.

## Требования к логике

1. **Контроль корректности:**
   - Если `ПараметрыПлатежа.СуммаПлатежа < 0`, функция должна вызвать исключение:
     `ВызватьИсключение "Отрицательная сумма платежа недопустима";`

2. **Принцип FIFO (First In, First Out):**
   - Заказы распределяются строго по возрастанию `ДатаЗаказа`.
   - При совпадении дат приоритет отдается меньшему значению `НомерЗаказа` (по возрастанию).

3. **Расчет задолженности:**
   - Остаток долга по заказу: `ОстатокДолга = СуммаЗаказа - ОплаченоРанее`.
   - Если `ОстатокДолга <= 0`, заказ считается закрытым и пропускается (в таблицу распределения не попадает).

4. **Выделение НДС:**
   - Расчетная сумма НДС в оплате рассчитывается по ставке заказа с округлением до 2 знаков:
     - Для `"20%"`: `Окр(СуммаОплаты * 20 / 120, 2)`
     - Для `"10%"`: `Окр(СуммаОплаты * 10 / 110, 2)`
     - Для `"Без НДС"`: `0.00`

5. **Возвращаемое значение:**
   Функция возвращает объект `Структура` со следующими свойствами:
   - `ТаблицаРаспределения`: `ТаблицаЗначений` с колонками:
     - `НомерЗаказа` (Строка)
     - `СуммаОплаты` (Число, фактически закрытая часть долга)
     - `СуммаНДС` (Число, выделенный НДС)
     - `ДолгПослеОплаты` (Число, остаток долга по заказу после распределения)
   - `ОстатокАванса` (Число): неизрасходованный остаток платежа (если сумма платежа превышает суммарный долг по всем открытым заказам, иначе `0.00`).
   - `ВсегоРаспределено` (Число): сумма всех распределенных оплат.
   - `ВсегоНДС` (Число): суммарный выделенный НДС по всем строкам распределения.

6. **Округление до копеек:**
   - Все денежные значения результата (`СуммаОплаты`, `ДолгПослеОплаты`, `ОстатокАванса`, `ВсегоРаспределено`) округляются до 2 знаков через `Окр(..., 2)`, чтобы шум арифметики с плавающей точкой не попадал в результат. Например, для заказов на `0.1` и `0.2` с платежом `0.3` строки распределения равны ровно `0.1` и `0.2` (а не `0.19999999999999998`), `ВсегоРаспределено` равно `0.3`.

## Критерий готовности
Модуль написан на корректном BSL, все базовые и приемочные тесты в `pytest tests/` успешно проходят.
